Private by design.

Can it open apps and games?

When supported by the browser and operating system, select an entire screen or a specific app/window in the browser's native screen-share picker.

Can it run secretly?

No. The browser requires a clear user gesture and permission to start screen capture. A visible browser sharing indicator remains in control.

Is this truly peer-to-peer?

WebRTC sends media directly when network conditions allow. This demo uses a public STUN server for connection discovery; some networks may require a TURN relay.

Why copy and paste?

A production one-tap pairing experience needs a signaling service (for example, a small WebSocket server) to exchange connection setup messages automatically.
